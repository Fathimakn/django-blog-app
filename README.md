A simple blog application built with Django that allows users to create,manage, and interact with blog posts. The project demonstrates core Django concepts like models, views, templates, authentication, and CRUD operations.
*Features
1) User Authentication – Register, login, and logout.
2) Post Management – Create, read, update, and delete blog posts.
3)Post Details – View individual blog posts with full content.
4)User Profile management – Each user can manage their own profile and posts.
